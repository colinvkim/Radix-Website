### Overview

Radix v1.4.1 is a small follow-up release that fixes several important issues from v1.4.0. It also improves performance during large scans. See the [full commit history between v1.4.0 and v1.4.1](https://github.com/colinvkim/Radix/compare/v1.4.0...v1.4.1) for a detailed development log. Stay tuned for the next major release, which will add support for multiple languages, a treemap view, and a scan comparison feature!

**Thanks for the continued support!** I’m always open to feedback, bug reports, and feature requests, so please keep sharing what would make Radix more useful for you.

### Highlights

- Cached hot-path lookup work in core scan/visualization code to keep large scans and disk-map interaction smoother.
- Improved Trash responsiveness so moved items disappear from Radix immediately (closes #15). Thanks @fraluc06 for pointing this out!

### Fixes

- Fixed search filtering so “current folder” matching stays consistent with visible file browser results.
- Fixed Discard Pile actions so staged items are not accidentally included in unrelated Trash actions. This fixes a critical bug where Trash actions would clear the Discard Pile.
