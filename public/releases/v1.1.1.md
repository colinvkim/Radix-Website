### Overview

I'm excited to announce that Radix is finally signed and notarized! This release does include a few reliability patches, but its primary focus is to offer a signed Radix build to users. See the [full commit history between v1.1.0 and v1.1.1](https://github.com/colinvkim/Radix/compare/v1.1.0-2...v1.1.1) for a detailed development log.

**Download [Radix v1.1.1 for macOS 26.0+ (universal binary for Intel and Apple silicon systems)](https://github.com/colinvkim/Radix/releases/download/v1.1.1/Radix.zip).**

### Highlights

- Improved scan performance for large cache-like directories that Radix auto-summarizes.
- Improved scan cancellation and failure cleanup.
- Added Sparkle EdDSA update signing support for future automatic updates.

### Fixes

- Fixed search behavior for queries with leading or trailing whitespace.
- Fixed tiny file sizes so byte-sized files display correctly.
- Hardened the Check for Updates menu state.
- Prevented stale whole-scan search results from appearing after quickly changing a query.
